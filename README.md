# Speed Reader

A private, phone-first reading app for one public-domain Project Gutenberg book (plain `.txt`).

Read one word at a time (RSVP) or with a moving highlight (pacer). All text stays on your device. Works offline as an installable PWA.

## Stack

Vite + React + TypeScript. Static site on Vercel. No accounts, no analytics, no backend.

## Develop

```bash
npm install
npm run dev
npm test
npm run build
```
